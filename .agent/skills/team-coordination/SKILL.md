# Team coordination

Use solo mode when one context can safely own the outcome. Use team mode when repository investigation, stack-specific implementation, or validation can proceed independently.

The orchestrator alone selects skills, searches Hermes, communicates with the user, and synthesizes results. Choose the smallest role set, cap parallel work at three, and give each writable worker a dedicated worktree plus disjoint path scope. Workers do not delegate.

Every brief includes role, goal, known evidence, allowed paths, out-of-scope work, and an `expectedOutput` matching the role bundle's exact `<final_answer>` contract. Use risk-based verification rather than invoking every reviewer automatically. Retry once, then surface the failure evidence.
